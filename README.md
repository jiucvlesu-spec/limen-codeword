# Орден «Лимен» — кодовое слово

Это вспомогательный репозиторий игрового мира «Ролевая-грань».
Здесь зафиксировано кодовое слово тайного ордена «Лимен», который хранит
знания о границах между мирами.

## Кодовое слово

**ТАВРО-ЛИМЕН-9QZ7-КРОВ-Δ17**

Слово передаётся только избранным. Оно не должно изменяться: любая транслитерация
(ТАВРО-LIMEN-9QZ7-KROV-D17) считается ошибкой передачи.

## Хронология фиксаций

- 2026-10-30 — первичная фиксация в этом репозитории.

## Правила

- Не сокращать слово и не заменять символ Δ на D.
- При цитировании в производных текстах сохранять регистр и дефисы.
